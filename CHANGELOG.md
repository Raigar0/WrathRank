# Changelog

## 0.4.1

- Show the score of equipped gear without suggesting a replacement for the other ring, trinket, or weapon slot.
- Use the off-hand weight when hovering an equipped off-hand weapon that can also go in the main hand.
- Prepare the weighted stat lookup when the scale changes, reducing work on the first hover over each item.
- Add installation instructions, project artwork, and MIT licensing with WoWSims attribution.

## 0.4.0

- Add class and talent tree dropdowns covering all 10 classes and 30 trees.
- Add manual Bear and Death Knight tank choices.
- Adapt published Wrath simulator weights and support separate main-hand and off-hand DPS weights.
